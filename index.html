HR Leave Management System

Efficiently manage employee leaves, attendance, and deductions with our comprehensive HR solution

Welcome to the Leave Management Portal

This system helps HR departments and employees track leaves, attendance, and related deductions in an organized and efficient manner.

Excel File Integration

The system reads employee data directly from an Excel file in the same folder.

  • Place your Excel file named employee_data.xlsx in this folder
  • Or use the sample file: sample_data.xlsx
  • HR Portal can manage and upload new data
  • Employee Portal automatically reads from the Excel file

Excel Upload

HR can upload and manage Excel files with employee leave and attendance data.

Leave Tracking

Track total annual leaves, sick leaves, leaves taken, and remaining leaves.

Late Attendance

Monitor late arrivals with date & time tracking and automatic deductions.

Real-time Data

Employee portal reads directly from Excel file for up-to-date information.

How to Use the System

  1. Step 1: Ensure you have an Excel file with employee data in this folder
  2. Step 2: HR personnel click "HR Portal" to upload/manage employee data
  3. Step 3: Employees click "Employee Portal" to view their personal details
  4. Step 4: The system automatically reads data from the Excel file
  5. Step 5: Update the Excel file to see changes in the Employee Portal
